## 解決方法 2：在運算過程中，「適時的」轉型成浮點數做運算

- 請比較 `(A - B) * 100. / A` 和 `(A - B) / A * 100.` 的差別
  - `(A - B) * 100.` ⇒ 轉為浮點；再 `/ A` ⇒ 除完 ∈ 浮點
  - `(A - B) / A` ⇒ 除完為 ℕ；再 `* 100.` ⇒ 轉為浮點 ⇒ 晚了！

- `1e+09` = 1 × 10^9（此類別 ∈ 浮點數）
- `double A = 300, cout << A;` ⇒ A = 3e9
- 如欲輸出 `300.000000`（小數點後 6 個 0），則用 `cout << fixed << A;`
- 然而，若浮點數太大（> 10^16、< 10^-16），則無法精確轉成 ℤ
  - 故 1000…0（18 個 0）= 1e18+3
  - 而 1000…0（18 個 0）< 1e18+3（long long）
- 如欲輸出小數點後 n 位，則用
  `cout << fixed << setprecision(n) << A;`
- 絕對誤差：|預期值 － 輸出值|
- 相對誤差：絕對誤差 / 預期值
- `int x = 0.7` ⇒ x = 0，`int x = -1.9` ⇒ x = -1
