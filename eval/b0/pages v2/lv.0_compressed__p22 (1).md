# 第??? 堂：卡拉楚巴 algorithm（分治）

- 令 X = (X₀·B^α + X₁)
- Y = (Y₀·B^α + Y₁)
- ⇒ X·Y = X₀·B^α·Y₀·B^α + X₀·B^α·Y₁ + X₁·Y₀·B^α + X₁·Y₁
- = Z₀·B^(2α) + Z₁·B^α + Z₂
- ⇒ 由上 ⇒ Z₀ = X₀·Y₀，Z₁ = X₀·Y₁ + X₁·Y₀，Z₂ = X₁·Y₁
- ⇒ 由分配率：Z₁ = (X₀ + X₁)(Y₀ + Y₁) － Z₂ － Z₀
- ⇒ 即分配率
