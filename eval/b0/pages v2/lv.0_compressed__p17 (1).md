## 在電腦 compile 正確，但上傳 wrong

1. 編譯器版本弄錯，例如使用了 gcd，但是確選 C++14
2. 傳錯程式碼
3. 使用了非 C++ 標準的語法或函式庫
4. 在全域變數使用太大量的記憶體（超過記憶體限制）
5. 在全域變數使用大量的記憶體（沒超過記憶體限制）且給初值

## Sample 正確，但其他 wrong

情境二：

1. 印出不可視字元或多印出空白或換行
2. 程式碼裡有未定義行為：
   - (1) 未初始話
   - (2) 整數溢位
   - (3) array index out of bound
   - (4) cin/cout 和 scanf/printf/puts 混用且使用了 I/O 優化
   - (5) I/O 優化寫在讀入之後
3. 加了 O3 以上的優化

## 上傳結果 RE

1. index out of bound
2. 整數溢位
3. 使用內建函式或工具傳錯參數
4. 整數除法獲取餘時有機會除以 0
5. 在函式裡（包括主函式）使用太多記憶體
6. OLE (Output Limit Exceed)

## TLE

1. 時間複雜度太大
2. 未定義行為也可能造成 TLE
3. 執行時間常數太大
4. 忘記使用 I/O 優化
5. 使用太多 endl
