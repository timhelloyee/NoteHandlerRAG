# 第四堂

- C++ 換位函式 `swap(a, b)`
- 如超出空間限制，用 `while (cin >> char)` 來讀值
- 如超出時間限制，以 `string` 直接讀值
- 在 C++ 中打 EOF：(ctrl+Z / ctrl+D)
- `int *x;` 與 `int x[];`（同樣的）
  - `// pointer of int`（一種資料形態，名為指標）
- `int *a = &d[0];`　`int *b = &d[3];`
  - `b - a = 3`
- ex. `int d[4] = {11, 12, 13, 14};`
  - `f(d);`
  - `void f(int *ptr)`
  - `{`
    - `cout << ptr;` ⇒ 陣列 d 的 bytes
    - `cout << *ptr;` ⇒ 11
    - `cout << *(ptr+2);` ⇒ 13
    - `cout << ptr[3];` ⇒ 14
  - `}`
- 指標：一个陣列放入的值，`(int)` 指標 ⇒ 一个陣列的 bytes
