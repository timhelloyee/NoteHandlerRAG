# 火山爆發

- 即刻：岩漿使氣溫 ↑
- 短期：火山灰／氣溶膠體，增加地球反照率，$T \downarrow$
- 長期：火山釋放 $CO_2$，增強溫室效應，$T \uparrow$

（頁面左側為「火山冬天原理」插圖：平流層氣膠、太陽輻射、吸收近紅外線、平流層增暖、細懸浮微粒之輻射、對流層氣膠、$SO_2 \rightarrow H_2SO_4$、火山灰、對流層降溫、太陽輻射總量減少、地表溫度下降）

# 前寒武紀以來氣溫變化

- 有數次長達千萬年尺度的冰室氣候
- ※現在是冰室氣候（溫室會更熱，沒有冰原）
  - 冰河期 ← 上一次：～2 萬年前
  - 間冰期 ← 現在

# 米蘭科維奇循環

※日地關係對地球氣候的影響

- ① 進動（歲差）　$T = 26000\ \mathrm{yr}$
  - 現在近日點為北半球的冬天
  - 自轉軸指向旋轉 $\frac{T}{2}$ 後，近日點變為北半球的夏天
- ② 地軸傾角變化　$T = 41000\ \mathrm{yr}$（$21.5^\circ \sim 24.5^\circ$）　※影響最大
  - 自轉軸傾角大 → 夏半球高緯度接收能量多（$0.5\% \sim 5.8\%$）
- ③ 地球公轉軌道偏心率變化　$T = 100000\ \mathrm{yr}$
  - 小：接近正圓 → 全年輻射量略少
  - 大：較為橢圓 → 全年輻射量略多

# ⇒ 有利於發展冰期的條件？

- 冰原冬天擴張 > 夏天縮減
- 地軸傾斜角小
- 冰帽半球在遠日點附近
- 公轉軌道偏心率小（近正圓）
