# 罪刑法定的內涵

- 1. 罪、刑明確
- 2. 禁止類推適用
- 3. 禁止習慣法
- 4. 禁止溯及既往 → 例外：行為後新法有利行為人時，可例外

※ 違法 ≠ 犯罪

# 犯罪成立要件

## 1. 該當性
- 構成要件
  - 客觀行為：犯行
  - 主觀意識：犯意（故意、過失）

## 2. 違法性（通常符合該當性，就具備違法性）
- 須考量「阻卻違法事由」

## 3. 有責性
- 年齡 → 責任能力
- 身心狀態 → 瘖啞人、心神喪失、精神耗弱
