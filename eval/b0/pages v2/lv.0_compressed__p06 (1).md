請思考看看，**計算數字個數** 這題的數字範圍若改變了…

1. 若數字範圍是 -1000000 至 1000000，還能用上課教的方法嗎？
2. 若要能使用此方法，出現的數字最大和最小值差距最大能多大？
3. 如果保證每個數字出現次數不超過 200 次，數字範圍能夠有多大，有簡單的方法能讓數字範圍更大嗎？
4. 若 a_i 的範圍非常大（如絕對值不超過 10^9），此題還能做嗎？或者有什麼時限調成 5 倍大就能通過的方法呢？
   Ans: Level 1 以後會教到的 map 這樣的東西可以用稍微差一些的時間解這題

1. 初始 2 倍大，`a[n + 10^6]`
2. 256 MB = 256 × 1024 KB = 256 × 1024² bytes
   - int = 4 bytes
   - (256 × 1024) / 4 ≒ 6.7 × 10^6
3. 把 `int` → `unsigned char`
