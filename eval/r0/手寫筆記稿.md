# R0 手寫筆記稿

> 用途：照著手寫成 8 頁筆記，拍照或掃描後，**同一份原始檔**分別上傳到 NotebookLM 與 NoteHandler。
> 題目與標準答案在另一份檔案 `題組與標準答案.md`。和 NotebookLM 只比**答案**（它的辨識稿看不到）；辨識正確率只在 NoteHandler 的不同版本之間比。**抄寫的人最好不要先看題目**，才不會無意間把答案寫得特別清楚。

## 抄寫須知

1. **一頁一張紙**，頁首照寫「第 N 頁」與科目、主題。頁碼是出處評分的依據。
2. 【圖】區塊是給你看的**畫圖說明**，請照著畫成圖：方框、箭頭、箭頭上的小字。
   - **說明文字本身不要抄進筆記。** 圖裡的資訊只能出現在圖上，不要在旁邊另外寫成句子。有幾題必須看懂箭頭才答得出來。
   - 箭頭方向很重要，請畫清楚。
3. 其他內容照一般寫筆記的習慣就好：可以條列、畫底線、圈重點、用「→」「∴」等符號。
4. **字跡保持平常的樣子**，不必刻意工整。第 3、6、8 頁可以寫得比平常快一點、潦草一點，用來測試辨識。
5. 數學式、化學式請照抄上下標，例如 CO₂、H₂O、C₆H₁₂O₆。
6. 完成後**一頁存成一張圖**，檔名 `R0_p1.jpg` … `R0_p8.jpg`。**不要合成 PDF**：合併後系統顯示的是 PDF 內的頁序，會和手寫的「第 N 頁」對不上，出處就無法評分。兩邊上傳同樣的檔案、同樣的檔名。
7. 上傳時照科目分開（對應實際使用方式）：

   | 類別 | 頁 |
   |---|---|
   | 地科 | R0_p1、R0_p2、R0_p3 |
   | 生物 | R0_p4、R0_p5、R0_p6 |
   | 歷史 | R0_p7、R0_p8 |

   NoteHandler 建立這三個類別並上傳到對應類別；NotebookLM 開三個 notebook，一科一個。

## 第 1 頁　地球科學｜板塊構造

**板塊構造學說**：地球表面的岩石圈分成許多板塊，板塊在軟流圈上緩慢移動。板塊的交界處是地震、火山最集中的地方。

**板塊邊界的三種類型**

| 類型 | 板塊運動 | 常見地形 | 例子 |
|---|---|---|---|
| 張裂型 | 互相分離 | 中洋脊、裂谷 | 大西洋中洋脊、東非大裂谷 |
| 聚合型 | 互相擠壓 | 海溝、島弧、褶皺山脈 | 日本海溝、喜馬拉雅山 |
| 錯動型 | 水平錯開 | 轉形斷層 | 美國聖安德烈斯斷層 |

- 喜馬拉雅山：印度板塊與歐亞板塊**陸陸碰撞**形成。
- **台灣**：位於菲律賓海板塊與歐亞板塊的交界，屬於**聚合型**，所以地震頻繁、山脈高聳。

## 第 2 頁　地球科學｜岩石循環

**三大類岩石**
- 火成岩：岩漿冷卻而成。
  - 噴出岩（在地表快速冷卻，顆粒細）：玄武岩
  - 侵入岩（在地下緩慢冷卻，顆粒粗）：花岡岩
- 沉積岩：砂岩、頁岩、石灰岩；常有**層理**，可能含化石。
- 變質岩：頁岩 → 板岩；石灰岩 → 大理岩。

【圖】岩石循環圖。畫 4 個方框：「岩漿」「火成岩」「沉積岩」「變質岩」，另外畫一個小方框「沉積物」。用箭頭連接，**箭頭上寫過程名稱**：

- 岩漿 → 火成岩，箭頭寫「冷卻凝固」
- 火成岩 → 沉積物，箭頭寫「風化、侵蝕、搬運、堆積」
- 沉積物 → 沉積岩，箭頭寫「壓密、膠結」
- 沉積岩 → 變質岩，箭頭寫「高溫高壓」
- 火成岩 → 變質岩，箭頭寫「高溫高壓」
- 變質岩 → 岩漿，箭頭寫「熔融」
- 變質岩 → 沉積物，箭頭寫「風化、侵蝕、搬運、堆積」（任何岩石變成沉積物都要經過這四步）

**只畫這 7 條箭頭**，不要加其他箭頭（例如沉積岩直接到岩漿），也不要在圖旁邊寫說明句子。排列方式隨意，畫成一圈最自然。

## 第 3 頁　地球科學｜地震

- **震源**：地下岩層破裂的起始點。**震央**：震源正上方的地表位置。
- **地震波**
  - P 波（縱波）：速度較快，最先到達；可以在固體、液體、氣體中傳播。
  - S 波（橫波）：速度較慢；只能在固體中傳播。
- **規模 vs 震度**

| | 規模 | 震度 |
|---|---|---|
| 意義 | 地震釋放的**能量** | 某地**搖晃的程度** |
| 數量 | 一次地震只有一個值 | 各地不同，通常離震央越遠越小 |

- 規模每增加 1，釋放的能量約增加 **32 倍**。
- 台灣的震度分為 **0～7 級**，其中 5 級、6 級再分「弱」「強」，共 **10 級**。

## 第 4 頁　生物｜細胞的構造

| 構造 | 功能 |
|---|---|
| 細胞核 | 含 DNA（遺傳物質），控制細胞的活動 |
| 粒線體 | 進行**細胞呼吸**，分解葡萄糖產生 **ATP**（細胞的能量來源） |
| 葉綠體 | 進行光合作用（詳見第 5 頁），只有植物等行光合作用的細胞才有 |
| 核糖體 | 合成蛋白質 |
| 內質網、高基氏體 | 修飾、包裝、運送蛋白質 |
| 細胞壁 | 支持、保護；植物細胞壁主要成分是纖維素 |
| 液胞 | 儲存水分與物質；植物細胞常有大型液胞 |

**動物細胞 vs 植物細胞**
- 植物細胞有：細胞壁、葉綠體、大型液胞。
- 動物細胞沒有細胞壁與葉綠體，但有中心粒。

## 第 5 頁　生物｜光合作用

- 場所：**葉綠體**。
- 總反應式：6CO₂ + 12H₂O →（光、葉綠素）C₆H₁₂O₆ + 6O₂ + 6H₂O
- 光合作用放出的氧氣，來自**水**的分解，不是來自二氧化碳。

【圖】光合作用兩階段流程圖。畫兩個大方框，左邊寫「光反應（類囊體）」，右邊寫「碳反應（基質）」。

- 有兩個箭頭**指進**「光反應」：一個寫「光」，一個寫「H₂O」。
- 有一個箭頭從「光反應」**指出去**，寫「O₂」。
- 有一條粗箭頭從「光反應」**指向**「碳反應」，旁邊寫「ATP、NADPH」。
- 有一條細箭頭從「碳反應」**指回**「光反應」，旁邊寫「ADP、NADP⁺」。
- 有一個箭頭**指進**「碳反應」，寫「CO₂」。
- 有一個箭頭從「碳反應」**指出去**，寫「葡萄糖」。

這些物質**只寫在箭頭旁邊**，不要另外寫「光反應產生……」之類的句子。

## 第 6 頁　生物｜人體血液循環

- 心臟有四個腔室：右心房、右心室、左心房、左心室。
- 心房與心室之間有瓣膜，防止血液倒流。
- 體循環：把養分和氧氣送到全身；肺循環：在肺部進行氣體交換。

【圖】血液循環路徑圖。畫成一個大的循環（像 8 字形或兩個圈都可以），方框與箭頭依序如下：

- 右心房 → 右心室，箭頭寫「三尖瓣」
- 右心室 → 肺動脈 → 肺部微血管 → 肺靜脈 → 左心房
- 左心房 → 左心室，箭頭寫「二尖瓣」
- 左心室 → 主動脈 → 全身微血管 → 上、下大靜脈 → 右心房

另外：
- 在「肺部微血管」旁寫「O₂ 進、CO₂ 出」。
- 用**兩種顏色**畫血管（例如紅色、藍色），並在角落畫圖例：紅 = 充氧血、藍 = 缺氧血。
  - 紅色：肺靜脈、左心房、左心室、主動脈
  - 藍色：上下大靜脈、右心房、右心室、肺動脈
- 如果只有一種顏色的筆，改成在血管旁寫小字「充氧」「缺氧」。

**血液的流動順序與顏色只畫在圖上**，不要另外寫成文字。
